# 🧩 Components Module

This directory contains all reusable and feature-specific UI components used across the **App**.  
The structure is organized to ensure **modularity**, **scalability**, and **maintainability**, supporting rapid development and consistent UI patterns.

---

## 📂 Directory Structure

```
components/
├── common/ # Shared layout and general-purpose components
├── movies/ # Feature-specific components for movie pages
└── ui/ # Base UI primitives (buttons, inputs, paginations, etc.)
```
